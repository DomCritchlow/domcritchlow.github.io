# Quick Links

Edit the JSON block below to add, remove, or change shortcuts. Each entry needs a `nickname` and `url`; `label` is optional and only affects how the link is shown on the list page.

```json
[
  { "nickname": "docs", "label": "Eleventy Docs", "url": "https://www.11ty.dev/docs/" },
  { "nickname": "github", "label": "My GitHub", "url": "https://github.com/DomCritchlow" }
]
```
